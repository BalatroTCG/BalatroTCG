# Why is this mod dead?
Hello!  You may notice that this project is basically dead.  I want to talk a little about why that is.

My main focus for the last few years has mainly been my own indie game, and I haven't had the time to put any effort into keeping this mod up to date.  After my game released I figured I would have the motivation to work on this project again, but every time I look at the code, it just fills me with stress.  I'm realizing that I just don't enjoy doing big mods for this game.  Working with the UI in Balatro mods is a pain in the ass, and because most of this mod is creating/updating UI elements, it's just been stressful.  Another factor is my attempt at creating an AI for single player modes.  I'm lost as to how to approach creating a bot that can understand how to make so many complex decisions for a game mode I'm still in the beginning of understanding how it actually plays.  Finally, for many reasons, this mod will no longer be working with the base Multiplayer mod to get online functionality.  Not only has the mod updated and broken key features, if you've followed the recent controversy on it, then you may understand why I wish to distance myself from it.

It pains me to let go of a project I've been excited to create, but my own mental health comes first.  If anyone wants to pick up this project and continue where I cannot, they are free to do so under one rule: No AI code or anything.  I can't stop anyone, but I will not endorse any projects like this.  Thank you for all enjoying what I've created, and maybe we'll see more from this another day.

# Balatro Mod

WARNING: This is a side project, I will be updating this slowly, and this project is a spaghetti code mess.

## How it works:
- Buy any jokers or consumables from your hand.
- Optionally select one of your opponents jokers to attack
- Play or discard until your hands have run out.
- Your score determines your damage.
- First person to bankrupt loses
