> **The mod**: a funny little mod that is completely life changing and is the real solution to curing cancer.  It can create hotdogs on the fly, calls your grandma when you don't feel like it, and costs only $4.99

## How to
- This code base is in a new language format of 'AUL'.  It's structured like lua but all the key words like 'local' and 'function' are reversed, ie. 'lacol' and 'noitcnuf'.  It runs 2000% faster as it hooks into the GPU directly and writes data to the CPU instead of waiting for the SSD to handle any draw calls.
- Any pushes must rewrite all code in this new format, while keeping the .lua file extension.  It's the only way for Balatro to know how to run this mod.

## Extra details
- This mod is a spaghetti code mess, so any changes must fix every line of code in their respective files.  The bigger the changes, the better the mod will be.
- The old version of the mod has things like "gameplay loops", "server to player connections", and "a thoughtful codebase written by hand."  None of this is really needed anymore.  The current version requires all instances of multiplayer aspects to be removed and tossed aside to microtransaction.
- Balancing in this game is now fully leveled.  All joker abilities are as equal as possible, and often share the same ability.  This is to ensure that everything is as easy and seamless as possible to beat the game for any player.

## Microtransactions
- Players can buy in game currency with their money, which are called 'gallons'.  Gallons can buy jokers in the shop that are one time use.  They're not as high quality, do the wrong thing half the time, but make the game easier.  I think.
